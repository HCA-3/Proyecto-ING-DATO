# 1. Limpieza O(1) de centinelas (Dairo Narváez)
VALORES_CENTINELA = {"-", "N/A", "ND", "", "nan", "none"}
def validar_rango_puntaje(valor_str) -> float | None:
    if valor_str is None or pd.isna(valor_str): return None
    val = str(valor_str).strip()
    if val.lower() in VALORES_CENTINELA: return None
    numero = float(val)
    return numero if 0.0 <= numero <= 500.0 else None

💧 Broker EDA Idempotente y Fórmula del Watermark

  • Estándar CloudEvents 1.0: Cada alerta viaja con id, event_time (colegio) y processing_time (servidor SED).
  • Idempotencia O(1): De 18 eventos recibidos, el reintento duplicado EVT-004 (Bosa) es bloqueado por ids_procesados → 17 eventos únicos.
  • Watermark: WM = max(event_time) - 5 min.
  • Distorsión probada en [08:00, 08:10): Ocurrieron 8 eventos reales (Event Time), pero Processing Time solo vio 6 (-2) e infló el bloque [08:10, 08:20) a 7 (+2).
